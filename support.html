Common questions

Is this a casino? No. The host types scores and cash-outs. The app does not take bets or play cards.

Do I need an account? No. The host phone keeps the night. A share code is optional.

Why contacts? So you can add players by name. You can refuse and type names.

A share code failed. Scoring still works offline. Try again on Wi‑Fi, or keep playing on the host phone.

I cancelled a game. Cancelled games are removed and are not kept in history.
